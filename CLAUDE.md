# Cinderbound — notes for Claude Code

Original 2D pixel-art, portrait-mobile, turn-based unit-collection RPG (inspired by the
*readability* of Brave Frontier, but with its own art, layouts, icons and identity — never copy
Brave Frontier assets, frames, fonts, icons or exact menu structure).
Built in **C++20 on Axmol 2.11.5** (cocos2d-x fork). v0.1–v0.5 were Godot 4.3 prototypes (last Godot
package: `releases/Cinderbound_Phase5_Windows.zip`). All art, audio and the pixel font are generated by the
Python scripts in `tools/` (they write into `Content/`).

## Working style
- Owner wants ponytail (minimal / lazy-senior-dev) mode on everything to save credits: smallest working
  diff, short replies.
- Don't merge to `main` unless the owner explicitly asks. C++ work lives on branch `cpp-axmol`.

## Architecture
- Design space 1080×1920 (FIXED_WIDTH when the window is taller than 9:16, else SHOW_ALL); pixel font on a
  10 px grid, font sizes multiples of 10; icons 16×16 scaled by whole numbers.
- `Source/logic/` — engine-free rules (`DB`, `GM`, SaveManager, Progression, SummonSystem, Battle model + AI).
  `Platform.h` is the only OS seam (PlatformAx.cpp in the game, Tests/PlatformStd.cpp in tests).
- `Source/ui/Gui.*` — Godot-style Control toolkit on Axmol (containers, anchors, size flags, Label, Button,
  ScrollContainer, Tween, Particles, AnimatedSprite, input router). `UIKit.*` — theme + shared widgets
  (PanelFrame, FantasyButton, FantasyPopup, ScreenBase, NavBar, StatusBar, ...). Porting/usage guide:
  `docs/dev/CPP_PORTING.md`.
- `Source/app/` — AudioManager, SceneRouter (`REGISTER_SCREEN("key", Class)`), UIManager, App::start.
- `Source/screens/` one .cpp per screen; `Source/screens/components/` shared widgets declared in `Screens.h`
  (Widgets.cpp: tabs/switch/element chart/settings panel; Rewards.cpp: rewards/stage info/energy/rank-up;
  UnitWidgets.cpp: unit card/filter/skill text/stat row/status icon/item sources).
- `Source/battle/` — battle screen (flow + SkillExecutor), views/effects/camera/stage, HUD, results.
- Content JSON in `Content/data/` (+ `manifest.json` from `tools/make_manifest.py`); JSON paths may keep
  `res://` — loaders strip it.

## Gotchas
- Windows macros: never name things `small`, `near`, `far`, `TRANSPARENT`, `ERROR`, `IN`, `OUT`, ... and never
  write `TEXT(`. `/home/claude/axcheck-win.sh file.cpp` checks with the common ones defined.
- Layout runs at end of frame: sizes are 0 while building; use `gd::defer` / `resized`.
- Non-premultiplied textures/DrawNodes need `ALPHA_NON_PREMULTIPLIED` blending (else they add white).
- `GM.unit(uid)` returns a reference to a shared null value when missing — copy before keeping it.
- Colours > 1.0 (Godot over-bright modulate) clamp to white.
