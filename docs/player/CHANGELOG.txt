CINDERBOUND - CHANGELOG
=======================

v0.5.0 - Phase 5: complete UI / UX improvement
----------------------------------------------
No new gameplay systems, worlds, heroes or currencies - this update is about
making every screen clearer, faster and more consistent. Saves carry over.

DESIGN SYSTEM
  * One set of text sizes (display 120 / title 80 / header 50 / name 40 /
    body 30 / meta 20) and spacing steps (4 / 8 / 12 / 16 / 24 / 32).
  * Buttons by meaning: primary (ember), secondary (steel), quiet (stone),
    reward (gold) and a new crimson danger button; hover, pressed, disabled and
    selected states; 0.25 s double-tap protection on every button.
  * New pixel art: tabs, ON/OFF switches, slider knob, slim scrollbars, tooltip
    plate, elite / perfect / cleared stage markers, tower paths and 17 new icons
    (back, help, info, filter, sort, plus, minus, close, pause, element chart,
    new, squad and five role icons).
  * Long names shrink, then shorten with "..." and a tooltip - no overflow.
  * Big numbers are shortened (12.4K, 1.3M) with exact values in tooltips.

NAVIGATION
  * Bottom bar is now HOME / QUEST / UNITS / SUMMON / MENU with an animated
    selected tab (sliding marker, icon pop).
  * BACK follows your real path through the menus, e.g. Units -> Details ->
    Evolution -> Where to find -> Tower -> BACK returns to Evolution.
  * Every screen has the same header: BACK, title, optional "?" help.
  * Slide transitions for going deeper / back, quick fades between tabs, ember
    dissolve for battles; "Reduce Motion" setting. Input is blocked mid-transition.
  * Esc closes popups / goes back (pause in battle); Enter confirms.
  * Loading cover only when a load really takes time (never a fake delay).

NEW SCREENS
  * QUEST hub (World Select): region cards with scenery, completion %, stars,
    boss state and what unlocks them, plus the Elemental Towers card.
  * MENU screen (replaces the menu popup) with large described tiles.
  * SETTINGS screen with AUDIO / GAMEPLAY / GRAPHICS / ACCOUNT tabs, sliders and
    switches; new Reduce Motion, Screen Margins and (phones) Vibration options.
  * HELP & GUIDE: Basics, Battle, Elements (element chart), Heroes, Progress.
  * TRAINING screen: Wisp cards with -1 / +1 / +5 / MAX and a live preview of
    level, EXP bar, stat gains and Gold cost.

SCREEN IMPROVEMENTS
  * Home: clear order QUEST > UNITS / SUMMON > TOWER / MISSIONS / SQUAD; heroes
    at the camp react when tapped; first-time guides ("Tap QUEST").
  * Top bar: animated currency changes (green gain / red spend), tooltips.
  * Stage map: distinct markers for new, elite, boss, cleared, 3-star and locked
    stages, each with a tooltip; possible drops explain themselves on hover/hold.
  * PREPARE and Squad: your squad's elements vs the foes' elements with one line
    of advice and a shortcut to the element chart (advice only, never blocks).
  * Units: indicators always in the same place on every card, role icons,
    FILTER & SORT overlay (element, rarity, role, can evolve, favourites; 10 sort
    options, high/low first, RESET) that is remembered; helpful empty state.
  * Unit Details: VIEW (full-size hero with animation buttons), best stat marked,
    short skill facts (targets, % ATK, hits, effects) above each description.
  * Evolution: WHERE TO FIND for every material, one confirmation listing
    exactly what is spent, EVOLUTION COMPLETE summary (new cap, Burst, Passive).
  * Summon: confirmation shows cost and Gems left; DUPLICATE results are marked
    with their Soul Shards; every result can be inspected.
  * Towers: floors connected by each tower's own path (ember / tide / verdant).
  * Missions: tab badges, CLAIM ALL, ticked login days.
  * Items: slot grid with a detail panel (WHERE TO FIND, USE only when usable).
  * Profile: name checked while typing (2-16 letters, numbers, spaces, - ' _).
  * Errors say exactly what is missing ("Not enough Gems. Need 1,000 - you have
    640.").

BATTLE
  * AUTO ON button plus a glowing AUTO BATTLE plate while heroes act alone
    (tap it to take control).
  * Boss plates show PHASE 1/2 and where phase 2 starts; DANGER - GUARD! pulses
    while a foe charges a big attack.
  * Status icons use the shared tooltip (hover / tap).
  * Damage numbers that land together stack instead of overlapping.
  * Pause menu: RESUME, ELEMENTS, SETTINGS, RETREAT (asks once).
  * Results: SKIP button, Enter to continue, several level-ups at once shown as
    LEVEL UP xN with the total stat gains.
  * Defeat: one tip that fits the fight (power, elements or tactics) and RETRY /
    EDIT SQUAD / STAGE SELECT with the retry Energy cost.

SOUND & FEEL
  * New sounds: back, confirm, error, coin, mission. One sound per meaning.
  * Optional vibration on phones for confirms, summons and evolutions.

TESTS
  * Updated click-through tests for the new menus; new Phase 5 full-flow test;
    resolution, long-text, extreme-resource and 100-hero / many-item checks.

v0.4.0 - Phase 4: hero collection, summoning, evolution, progression, repeatable PvE
-----------------------------------------------------------------------------------
All heroes, enemies, portraits, summon and evolution art, icons, sounds and music
are original to Cinderbound.

HEROES & ROSTER
  * 12 heroes, 4 per element, 27 forms in total, each with its own sprite sheet
    (idle, attack, hit, guard, Burst, victory, KO) and portrait:
      Fire   Kael Emberclaw 3-5*, Rhea Flintwhistle 3-5*, Voss Ashmantle 4-5*,
             Seraphine Pyrelance 5*
      Water  Mira Tidesong 3-5*, Corin Saltmarsh 3-5*, Nerys Frostwake 4-5*,
             Aldric Deepvow 5*
      Nature Thorne Mossguard 3-5*, Wren Briarshot 3-5*, Faye Lumenbloom 4-5*,
             Gorran Oakheart 5*
  * Roles (Attacker, Healer, Defender, Support, Breaker), HP/ATK/DEF/REC with
    data-driven growth, rarity-based level caps (15 / 25 / 35).
  * Every form has a normal attack, a Burst, a Passive and a Leader Skill
    (e.g. Kael: Fire allies +8% ATK; Mira: +healing received for the squad;
    Rhea: faster Burst gauges; Voss: +damage to debuffed foes).
  * The three starters gained two evolved forms each with visible changes
    (Kael: cape, crest, second pauldron, longer blade; Mira: circlet, longer
    cloak, orbiting droplets; Thorne: antlers, leaf cape, tower shield).
  * Lock and Favourite flags; NEW markers; Codex of every hero line (Owned X/12,
    silhouettes for heroes you have not met).

TRAINING, BURST LEVELS, EVOLUTION
  * TRAIN with Ember / Tide / Verdant / Radiant Wisps + Gold: live preview of
    Lv now -> new Lv, stat gains, Gold cost and wasted EXP; AUTO SELECT.
  * Burst levels 1-5 (Burst EXP from using Bursts in won battles, Spark Sigils or
    Soul Shards). Upgrades differ per Burst: damage, healing, shields, buff
    strength, extra turns, status chance, ally Burst gain or lower gauge cost.
  * EVOLVE screen: current -> next form, stat comparison, materials with owned /
    needed, OBTAINED FROM with GO navigation, Gold cost, level requirement and an
    evolution ceremony. No duplicate heroes required.
  * Materials: Ember / Tide / Sprout Fragments, Flame / Current / Verdant Cores,
    Infernal / Abyss Crystals, Ancient Seeds, Prism Shards.

EMBERGATE SUMMONING
  * Standard banner: 100 Gems per summon or 1000 for x10; rates 75% / 22% / 3%
    read from data and shown in DETAILS with every hero's exact chance.
  * Ceremony: fragments -> gate flare -> rarity light and stars -> silhouette ->
    reveal -> NEW!. SKIP appears after your first summon. Results are saved before
    the animation. Duplicates become Soul Shards (10 / 30 / 100) with an
    explanation. NEW hero flow: DETAILS / ADD TO SQUAD / CONTINUE.

SQUAD & BATTLE
  * Squads of up to 5 heroes, leader slot with Leader Skill, add / remove / swap,
    no hero twice, Squad Power (advice only - never blocks entry).
  * Auto Battle (unlocks after 1-4) and 1x / 2x speed, remembered in Settings.
  * New statuses and effects: Poison, Regen, ATK/DEF Down, REC Up, Shields that
    absorb damage, ally Burst gain, cleanse, team auras.
  * Readable enemy AI profiles: attacker, healer, tank, buffer, debuffer, charger,
    boss patterns. Charged attacks are telegraphed with a WARNING banner and a
    glowing enemy. Bosses call minions, react at HP thresholds and enrage in a
    second phase. Elites (gold frame + ELITE tag) use an extra skill.
  * Star objectives per stage (clear, no KO, turn limit / Burst count), stage drop
    lists and first-clear Gems (5, bosses 25).

ENEMIES (29 variants)
  * Slime family in all three elements (Cinder, Tide, Moss), Bramble Pup, Tidefin,
    Glowcap (healer), Emberwisp (buffer), Hexmoth (debuffer), Scorch Beetle
    (charger), Shellcrab (tank), Brine Eel, Drift Jelly (healer), Salt Wraith
    (debuffer), 8 elites, the Ancient Bramble Pup, the Saltglass Colossus and six
    tower guardians (Scorch Matriarch, Emberwisp Tyrant, Deepwater Matron, Brine
    Leviathan, Elder Glowcap, Thornback Elder).

CONTENT
  * World 1 polished: energy costs, recommended power, drops, stars, new mixed
    waves with healers, buffers, debuffers and an elite, and gradual unlocks
    (Auto 1-4, Units/Squad + gift hero 1-5, Training 1-6, Towers 1-7, Evolution 1-8,
    Summon + 150 Gems 1-9, Missions + World 2 after 1-10).
  * World 2 - Saltglass Reach: 10 stages across a salt-glass shore, sea caves, a
    stranded warship and the Saltglass Spire, new map and battle backgrounds,
    new music, a new mechanic (curses that lower DEF and shell-raising tanks) and
    the Saltglass Colossus boss (curse, charged Shatterstorm, cracks and enrages
    below 50% HP).
  * Elemental Towers: Ember, Tide and Verdant, 10 floors each with escalating
    difficulty and Energy cost, guardian bosses on floors 5 and 10, first-clear
    Gems and a Prism Shard at the top.

META
  * Energy with offline regeneration (1 per 3 minutes), safe against clock
    changes; Max Energy grows with Rank.
  * Player Rank: RANK UP presentation, Energy refill, Max Energy increases and
    50 Gems every 5 ranks.
  * Daily missions (5) + Daily Chest, weekly missions (4), 7-day login calendar
    where missed days continue the cycle.
  * Inventory tabs (Materials / Training / Items / Other) with stacking and
    OBTAINED FROM for every item.
  * Economy: Gold, Gems and Soul Shards - all earned in play, no pay-to-win.

SCREENS
  * New status bar (Rank, Energy + timer, Gems, Gold) on every screen.
  * Home: squad campfire, QUEST, UNITS / SQUAD / SUMMON / TOWER / ITEMS / MISSIONS
    tiles with locks and red notification markers; login reward and feature
    unlock popups on arrival. Bottom bar: HOME / UNITS / QUEST / SUMMON / MENU.
  * Quest map with world tabs, stars on cleared nodes and the full stage sheet;
    PREPARE popup (squad, leader skill, power check, EDIT SQUAD, DEPART).
  * New screens: Embergate, Towers, Evolution, Codex, Missions, Profile.
  * Victory: star objectives, first-clear Gems, Burst level ups, unlocks, gift
    hero, world cleared, RANK UP overlay.
  * Settings: Start Battles on Auto, Default Battle Speed.

SAVES
  * Save format v2 with automatic migration: nothing is wiped. Old shards turn
    into Fragments, over-cap heroes are set to max level (ready to evolve), cleared
    stages keep a star, milestone gifts are granted retroactively and a one-time
    note explains the update.

TECHNICAL
  * Data-driven: heroes, skills, enemies, AI, stages, towers, drop tables, summon
    banners, missions, login rewards and unlocks live in data/*.json
    (see CONTENT-GUIDE.md); references are validated on start.
  * Clean shutdown (no leaked audio streams).
  * Tests: 2,000+ rule checks (energy / offline / clamping, training, evolution,
    summon rates and duplicates, missions and login, migration, AI, bosses,
    shields, stars, anti-softlock), click-through flows for the whole Phase 4
    loop, balance simulation of both worlds and all towers.

v0.3.0 - Phase 3: graphics, combat presentation and UI/UX overhaul
------------------------------------------------------------------
Every piece of art, UI, sound and music is original and generated for Cinderbound.

UI THEME & COMPONENTS
  * New "worn iron and ember" UI kit: layered metal frames, inset stone panels,
    wooden planks, element-framed cards, rarity frames (3-6 stars), raised buttons
    with pressed / hover / disabled art, carved separators.
  * Reusable components: FantasyButton, PanelFrame, ResourceBar (animated lost
    section), StatusIcon (tap/hold/hover tooltip), UnitCard, StatRow, RewardItem,
    StageNode, EnemyPlate, ScreenHeader, NavBar, CurrencyDisplay, FantasyPopup,
    Toast, CoachMark, CutinDecor.
  * Consistent 16x16 icon family (elements, gold, EXP, rank, nav, statuses, gestures).
  * Text sizes locked to a pixel grid (no blurry or tiny text).
  * Buttons squash and click, main buttons have a light sweep, popups open/close
    with sounds.

BATTLE HUD
  * Top bar: stage, wave pips, gold and drops found, MENU.
  * Enemy plates: element, name, level, HP bar with lost section, HP %, statuses,
    target marker; bosses get a large crimson frame and an ANCIENT FOE tag.
  * Animated ember target sigil under the target + bobbing marker above it.
  * Hero cards: big portrait, element frame, HP with healthy/injured/critical
    colours, Burst gauge EMPTY / CHARGING / READY (glow, pulse, sparks, chime),
    statuses, KO stamp, lift + direction arrow while swiping.
  * Wave banners and a boss banner; compact action log.

COMBAT PRESENTATION
  * Layered portrait battlefields (far / mid / ground / foreground) with parallax
    and ambient motion: leaves & light rays, dust, embers & smoke, water shimmer
    & fog, glowing spores. Formations now have real depth.
  * Anticipation before lunges, knockback on hits, guard stance + shield marker,
    enemy special attacks with a glowing wind-up.
  * Impact: hit flash, element particle bursts, impact screen flash, brief
    hit-stop, tiered screen shake (tiny / strong / Burst finisher / boss).
  * Damage numbers by type: normal, CRITICAL, ADVANTAGE, RESIST, heal, burn,
    and big FINISH numbers for Burst finishers.
  * Burst sequence: darken -> element cut-in (hero, name, Burst name) ->
    charge-up -> attack -> finisher.
      Kael: ember streaks, rapid slash trails, heavy fire finisher.
      Mira: flowing water ribbon, bubbles, blue ring, healing pulse on allies.
      Thorne: creeping roots, earth fragments, shield domes, green pulse.
  * Boss entrance: wave pauses, screen darkens, silhouette stalks in with heavy
    steps, ANCIENT FOE title and sting, colour returns.
  * Ancient Bramble Pup redrawn: bigger, stone thorn ridge, glowing runes,
    pulsing idle, special attack.

CHARACTERS
  * New guard animations for Kael, Mira and Thorne; all heroes and enemies drawn
    larger on the field.

SCREENS
  * Home: interactive camp - heroes around an animated campfire (tap the leader
    for a flourish, tap others to focus them), big QUEST, UNITS and ITEMS plates,
    SUMMON / SHOP clearly locked.
  * Quest: new portrait adventure map climbing to the Heart of Ashroot, node
    states LOCKED / AVAILABLE / CLEARED / BOSS, marching trail, docked stage sheet
    with rewards, enemy elements, first-clear bonus and a big START.
  * Units: rarity-framed cards, element filters, sort by recent/level/rarity/ATK/HP.
  * Unit Detail: large showcase (tap to animate), class, stat bars, Burst and the
    effects it grants, TRAIN, SQUAD, EVOLVE (locked), lore.
  * Squad editor with leader emblem, slot swapping, MAKE LEADER; built for 5.
  * Items with category tabs.
  * Victory: sequenced reveal - party, EXP counting up, bars filling, LEVEL UP
    stamp + sound, gold counting, items popping into slots, first-clear bonus,
    CONTINUE / RETRY. Defeat: RETRY / PARTY / STAGES.
  * Settings: Battle Effects, Damage Numbers and Reset Tutorial added.

TUTORIAL, TRANSITIONS, AUDIO
  * Coach marks: the screen dims around the control to use, with an animated hand
    or swipe arrow ("Tap Kael to attack.", "Swipe up..."). Done once, resettable.
  * One transition manager: quick fades for menus, ember dissolve into and out of
    battle.
  * New sounds: menu open/close, unit select, stage select, target, burst ready,
    reward, boss sting, impact.

TECHNICAL
  * Existing saves load unchanged (new fields are added automatically).
  * 700 rule checks + click-through milestone flow pass for all three starters;
    checked at 720x1280, 1080x1920, very tall and landscape windows.
