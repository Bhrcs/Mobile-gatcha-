# Cinderbound balance guide

Every number lives in data: `Content/data/progression.json` (`combat`, `break`, `burst`), hero/enemy/skill JSON
(generated by `tools/make_content.py`). Formulas live in `Source/logic/Battle.cpp` (`DamageCalculator`).
Re-check balance with the simulator: `bash Tests/run_logic_tests.sh audit`.

## Damage
```
raw        = ATK x skill.power
mitigated  = max(raw - DEF x 0.3, raw x 0.1, 1)
taken      = (1 - armour status) x (1 - passive damage_taken_down [max 0.5]) x guard     # guard = 1 - (0.5 + guard_bonus) [max 0.8]
taken      = max(taken, 1 - max_mitigation)                                            # max_mitigation 0.75: no immortal teams
final      = mitigated x element x crit x variance x taken x (1 + damage_bonus_vs) x (1 + vulnerability)
```
* element: advantage x1.25 (tag WEAK), disadvantage x0.75 (RESIST).
* crit: 5% base + crit passives, x1.5. Crit is one knob among many; no crit stacking beyond passives.
* variance: 0.95-1.05. No damage caps.
* vulnerability: strongest `damage_taken_up` status (Broken = +50%).

## Healing & shields
* heal = target max HP x percent_max_hp + caster REC x rec_multiplier, x (1 + heal_received_up). REC always matters.
* shield = caster max HP x percent_caster_hp; absorbs before HP; one shield at a time (stronger replaces weaker).

## Stats
* ATK/DEF/REC buffs are `stat_mod` statuses. **Stacking:** the same status never stacks (the stronger value and the
  longer duration are kept); different statuses on the same stat add up, capped at **+-60%** (`status_stat_cap`).
  Passives and leader skills are separate multipliers.
* Damage reduction statuses (Bastion, Flame Armor): only the strongest counts, then the 75% total cap applies.
* DoTs: Burn 5% max HP / turn, Poison 4% / turn. A DoT does not stack with itself (refresh = keep longer duration).

## Status resistance (Phase 7)
* Enemy data `resist: {status: chance}`; bosses default to **30%** (`boss_status_resist`).
* Diminishing returns: each time a status lands on a boss its resist rises by **15%** (`boss_status_dr_step`) for that
  battle, so control/debuff chains get less reliable instead of being immune from the start.
* Resisted statuses show "RESISTED".

## Dispel / Cleanse
* **Dispel** (Breakers' Bursts: Rending Quake, Magma Sunder, Grove Quake) removes enemy buffs. Statuses with
  `"dispellable": false` (Flame Armor, Ember Fervor) say so in their description and need the mechanic instead.
* **Cleanse** removes negative statuses from allies (healers).

## Break Gauge (Phase 7)
* Only bosses/elites with a `break` block have one (`{"max": N, "weak": element}`).
* Break per action = 12 (`break.base`) x skill power x 2.0 for Breakers x (1.5 if the attacker is the boss's break
  weakness, else the element multiplier). Split across the skill's hits. Enemies never break heroes.
* At 0: **BROKEN** for 2 turns - loses its turns, its charged attack is cancelled, `removed_by_break` armour
  shatters, takes +50% damage. The gauge refills when Broken ends.

## Bosses (Phase 7)
* Data-driven: `ai.pattern` (steps: normal / charge / curse / heal / any skill id), `ai.actions` (actions per round),
  `ai.phases` = `[{below, atk_up, pattern, announce, summon, charge, skill}]`, `start_statuses`, `break`, `resist`,
  `mechanics` (text shown to players). Summoned enemies with `aura` buff every boss while alive.
* Telegraphed attacks (charge) show "DEVASTATING ATTACK" and how to stop them. Skill `interrupt`
  (`{break, damage_percent}`) cancels the charge when met.
* Boss HP ranges: story bosses 760-1400 base (x level scaling), Fracture bosses 2400+ base with 2 actions/round.

## Enemy level scaling
`stat = base x (1 + per_level x (level - 1))` with per_level hp 0.20, atk 0.11, def 0.10, spd 0.03.

## Reference values
| | range |
|---|---|
| Normal attack power | 1.0-1.3 over 1-3 hits |
| Burst power | 2.0-3.0 (single) / 1.6-2.2 (all), +0.10-0.12 per Burst level |
| Heals | 20-35% max HP + REC x 1.0-1.5 |
| Buffs / debuffs | 15-30%, 2-3 turns |
| Status chance | 15-40% on normals, 60-100% on Bursts |
| Squad power | stage `recommended_power` (see `ref_power` in make_content.py) |

## Audit log
**Phase 7 slice 1 (simulator, 30 seeds, players use the form they would have at the stage level):**
* World 1-2 at recommended level: starter trio and 5-hero squads clear 100% with no KOs; 2-hero mono-fire fails the
  World 2 boss (20%). Fights run long (World 2: 18-35 rounds for 2-3 waves) - enemy healers + Shellcrab armour stall
  weak-damage squads. Dispel/DEF-down/Break are the intended answers; revisit in the balance pass (step 22).
* The old simulator never triggered boss phase 2; it now plays phases, summons and charges like the game.
* Fracture I (Ashen Warden, 2 actions, Flame Armor, totems, Furnace Collapse): trio of starters wins slowly
  (16-25 rounds); adding a Breaker + a Water hero halves the fight (9-13 rounds); mono-fire trio loses Hard/Expert.
  Composition matters - that is the goal.
